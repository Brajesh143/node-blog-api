Node.js — Performance & Reliability
============================================

Theory — 45 min
----------------

    A. API Timeout:
    -----------------

        Why do we need:

            Client
            ↓
            API
            ↓
            External Service

        If the external service hangs for 60 seconds, your API shouldn't wait indefinitely.

        Understand:

            Request timeout
            Connection timeout
            Socket timeout
            Upstream timeout

    B. Retry:
    ---------

        Review:

            Request
            ↓
            Failure
            ↓
            Retry
            ↓
            Exponential Backoff
            ↓
            Success / Final Failure

        But understand an important rule:

            Don't retry every error.

            For example:

                400 → Don't retry
                401 → Usually don't retry
                403 → Don't retry
                404 → Usually don't retry
                429 → Retry after appropriate delay
                500 → Potentially retry
                503 → Potentially retry

    C. Rate Limiting:
    ------------------

        Understand why APIs need protection.

        Example:

            Normal user
            → 100 requests/min

            Attacker/Buggy client
            → 100,000 requests/min

            Rate limiting can protect:

                API servers
                Database
                Third-party APIs
                Authentication endpoints

            Know the basic idea of:

                Fixed window
                Sliding window
                Token bucket


    D. Graceful Failure:
    ---------------------

        A production API should not simply crash because one dependency failed.

        Think:

                    API
                    ↓
            ┌──────┴──────┐
            ↓             ↓
            Database      External API
            ↓             ↓
            Success       Failure
                            ↓
                        Fallback /
                        Retry /
                        Error

        Learn:

            Graceful degradation
            Circuit breaker — concept only
            Fallback
            Health check
            Dependency failure

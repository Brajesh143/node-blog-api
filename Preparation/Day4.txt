Node.js — Event Loop & Performance
-------------------------------------

Theory:
-------
    A. Event Loop phases

        Understand the high-level flow:

            JavaScript
                ↓
            Call Stack
                ↓
            Async operation
                ↓
            OS / libuv
                ↓
            Callback queues
                ↓
            Event Loop
                ↓
            Call Stack

        Learn the important Node.js concepts:

            Call Stack
            Event Loop
            libuv
            Timers
            I/O callbacks
            Poll phase
            Check phase
            setImmediate()
            process.nextTick()
            Promise microtasks


    B. Microtasks vs Macrotasks

        Understand the priority roughly as:

            Synchronous code
                ↓
            process.nextTick()
                ↓
            Promise microtasks
                ↓
            Macrotask / Event Loop phases


    C. CPU-bound vs I/O-bound

        This is extremely important for Node.js interviews.

        I/O-bound

            Examples:

            Database query
            API call
            File read
            Network request

        CPU-bound

            Examples:

            Large image processing
            Video encoding
            Huge calculation
            Complex data processing

        These can block the JavaScript thread.

            Learn possible solutions:

            Worker Threads
            Child Processes
            Separate services
            Background jobs

Node.js Practical:
-------------------

    Exercise 1 — Predict the output — 15 min
    
        Question 1
            console.log("A");

            setTimeout(() => console.log("B"), 0);

            Promise.resolve().then(() => console.log("C"));

            process.nextTick(() => console.log("D"));

            console.log("E");

            Predict the output without running it.

            Then explain why.

        Question 2
            console.log(1);

            setTimeout(() => console.log(2), 0);

            setImmediate(() => console.log(3));

            Promise.resolve().then(() => console.log(4));

            process.nextTick(() => console.log(5));

            console.log(6);


    Exercise 2 — Find the blocking code — 10 min

        Consider:

        app.get("/report", (req, res) => {
            const result = hugeCalculation();

            res.json(result);
        });

        Assume hugeCalculation() takes 10 seconds.

        Answer:

        What happens to other requests?
        Why?
        Is this I/O-bound or CPU-bound?
        How would you fix it?
